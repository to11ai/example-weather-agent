# Security

If you believe you have found a security vulnerability in this repository or in
the to11 platform, please report it responsibly.

**Do not open a public GitHub issue** for security-sensitive bugs.

Instead, please report it here:

- **[Report a security vulnerability](https://github.com/to11ai/example-weather-agent/security/advisories/new)** — use GitHub's Security Advisories to submit a private report.

We will respond as soon as we can and will keep you updated on the status of the report.
